# ⚛️ SepsisGuard React: The Predictive Interface

This is the frontend implementation of the **SepsisGuard AI Clinical Portal**, submitted for Hackathon 2024.

## 🚀 Hackathon Highlights
*   **Real-time ICU Monitoring:** 60FPS UI powered by React 18 and Vite.
*   **Predictive Simulation:** Digital Twin logic for bedside intervention planning.
*   **Clinical Glassmorphism:** A custom-built design system for high-stakes medical environments.
*   **AI Explainability:** SHAP-driven visual data layers for model transparency.

## 🛠️ Tech Stack
*   **Core:** React 18, Vite
*   **Styling:** Vanilla Tailwind CSS
*   **State:** React Hooks + Context API
*   **API:** Axios (pointing to SepsisGuard Node.js Backend)
