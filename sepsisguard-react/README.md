# ⚛️ SepsisGuard React: The Clinical Front-End

Welcome to the heartbeat of the SepsisGuard system. This React-based dashboard is engineered for high-stakes ICU environments where clarity and speed are non-negotiable.

---

## ⚡ KEY INTERFACES:

1.  **🎛️ Unified Command Center:** Real-time patient monitoring with glassmorphic risk indicators.
2.  **📈 Dynamic Risk Trajectory:** A sub-pixel precise SVG mapping of historical sepsis trends.
3.  **💊 The Intervention Simulator:** A "What-If" engine that calculates future clinical outcomes.
4.  **🧠 SHAP Explainability:** Visual breakdown of the AI's decision-making process.
5.  **💬 Global AI Assistant:** facility-wide intelligence at your fingertips.
